# TypeScript 生成签名索引

本页是 TypeDoc 生成签名索引的入口。它只反映本次构建使用的 `packages/ts/src/index.ts` 公共导出，不替代中文的任务说明、协议边界和失败案例。

## 中文 API 说明

请阅读 [TypeScript API 详解](/manual/typescript/api/)。该目录按公共工具、SM2、SM3、SM4、ZUC 和 SHA 组织，说明参数编码、默认值、返回值、错误条件和状态变化。

## 生成内容

当前版本的完整签名索引由站点构建生成。历史版本从对应 `ts-vX.Y.Z` tag 重新生成，版本清单位于 [API 说明书](/api/#已发布版本签名索引)。

TypeDoc 页面用于核对名称、类型和重载；固定向量、跨语言字段和安全边界以中文手册及算法页为准。
